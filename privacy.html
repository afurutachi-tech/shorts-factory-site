shorts-factory プライバシーポリシー

制定日: 2026年11月20日

このアプリについて

shorts-factory は、運営者自身の YouTube チャンネルに、運営者が制作した動画を非公開でアップロードし、運営者が承認した動画だけを公開し、その再生指標を記録するための社内ツールです。第三者の利用は想定していません。

取得する情報

  • 運営者の YouTube チャンネルへのアップロードと公開設定の変更に必要な権限（OAuth 2.0）
  • 運営者のチャンネルの動画の公開状態・再生回数・高評価数・コメント数、および YouTube アナリティクスの指標（有効視聴、平均視聴率、登録者の増減、推定収益）

利用目的

動画の非公開アップロード、運営者の承認後の公開、公開後24時間・7日の指標の記録のためだけに使います。

保存と共有

認証情報は GitHub Actions の暗号化されたシークレットにのみ保存し、指標は運営者の非公開リポジトリに記録します。取得した情報を第三者に販売・共有したり、広告に利用したりすることはありません。

アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/connections）から、いつでもこのアプリのアクセスを削除できます。

本アプリは YouTube API サービスを使用しています。YouTube 利用規約および Google プライバシーポリシーが適用されます。
